# mypibypy

## Streamlit

The UI is Streamlit (`mypibypy/app.py`, `mypibypy/app_help.py`, `mypibypy/src/mypibypy/ui.py`). Before writing or changing Streamlit code, read the official skill at `.agents/skills/developing-with-streamlit/SKILL.md` (also available as the `developing-with-streamlit` skill). It is a local symlink into the installed Streamlit package and is gitignored; if it is missing, reinstall it from the Streamlit toast or skip it.
